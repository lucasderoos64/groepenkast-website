## Live zetten op GitHub Pages

1. Maak een nieuwe GitHub repository aan.
2. Upload de inhoud van deze map naar de root van de repository.
3. Ga in GitHub naar `Settings` > `Pages`.
4. Kies bij `Build and deployment` voor `Deploy from a branch`.
5. Selecteer branch `main` en folder `/root`.
6. Klik op `Save`.

De site komt daarna beschikbaar via de GitHub Pages URL.
